# いいかいご テレッサ（実地調査対応・モック）

訪問介護サービス提供記録（テレッサ）を、実地調査（運営指導）で提示・印刷・提出できる形で表示するWebシステム。
表示データはすべて架空のモックデータ（`lib/mock.ts`）。

## 起動

```bash
cd web
npm install
npm run dev     # http://localhost:3000
npm test        # 算定区分・自動チェックのテスト
npm run build
```

## 画面

| パス | 内容 |
|---|---|
| `/` | ダッシュボード（件数・単位数・概算金額・チェック結果・調査当日の流れ） |
| `/audit` | 実地調査チェック（12項目の自動チェック結果、指摘のある記録へのリンク） |
| `/records` | 記録一覧（利用者・職員・期間・算定区分・報告あり/要観察/訂正ありで絞り込み） |
| `/records/[no]` | テレッサ1枚の表示・印刷、作成/確認日時、訂正履歴 |
| `/print?…` | 絞り込み条件のテレッサをA4縦・1件1ページで一括印刷 |
| `/api/records.csv?…` | 絞り込み条件の記録をCSV出力（Excel対応のBOM付きUTF-8） |
| `/users`, `/users/[id]` | 利用者一覧、計画と実績の突き合わせ表（日別） |
| `/staff` | 職員の資格・身体介護の可否・担当件数 |
| `/summary` | 利用者別の月間集計（回数・時間・単位数・金額） |

## 自動チェック（`lib/checks.ts`）

C01 算定区分と提供時間 / C02 計画区分と実績 / C03 計画外の訪問 / C04 2時間ルール /
C05 サービス内容と区分 / C06 特記事項の記載 / C07 利用者確認 / C08 サ責確認 /
C09 資格要件 / C10 職員の訪問重複 / C11 訂正履歴の理由 / C12 異変時の報告記録

## 定数（`lib/master.ts`）

- 大阪市2級地 訪問介護 11.40円/単位（2027年4月の介護報酬改定で見直し）
- 基本単位は2024年度改定値。加算は未計上

## Firestore への切り替え

データ取得は `lib/data.ts` に集約している。Firestore を使う場合はこのファイルの実装だけを差し替える。
