# いいかいご テレッサ（運営指導対応）

訪問介護の **サービス提供記録（テレッサ）・訪問介護計画・介護報告書** を一元管理し、
大阪市の運営指導で提示・印刷・提出できる形にするWebシステム。

初期表示は架空のモックデータ（2026年9月分）。利用者リスト・職員・訪問介護計画・サービス提供記録を取り込むと、取り込んだデータに切り替わる。

## データの保存場所

取り込んだデータはブラウザの IndexedDB にだけ保存し、サーバーには送信しない（個人情報を外に出さないため）。
端末・ブラウザ間で共有はされないので、取り込み画面の「バックアップ（JSON）」で保存すること。
複数職員での共有には、ログイン付きの Firestore への切り替えが必要（`lib/store.tsx` を差し替える）。

## 起動

```bash
cd web
npm install
npm run dev     # http://localhost:3000
npm test        # 算定・取り込み・運営指導チェック・報告書のテスト
npm run build
```

## 画面

| パス | 内容 |
|---|---|
| `/` | ダッシュボード（件数・単位数・概算金額・チェック結果・期限が近い計画と認定） |
| `/audit` | 運営指導チェック（18項目） |
| `/records` `/records/[no]` `/print` | 提供記録の一覧・絞り込み・CSV出力、テレッサ様式の表示、A4一括印刷 |
| `/plans` `/plans/[id]` | 訪問介護計画の一覧、計画書（A4）の表示・印刷 |
| `/reports` `/reports/[id]` | 介護報告書（月次実施報告）の自動下書き・編集・確定・送付記録・訂正履歴・印刷 |
| `/shifts` `/shifts/[staffId]` | シフト：計画から月の訪問予定を作り、職員へ自動で割り当て。手動変更・固定、全体表、職員ごとの訪問予定表（A4）、CSV |
| `/users` `/users/[id]` | 利用者一覧、計画と実績の突き合わせ表（月別） |
| `/staff` `/summary` | 職員の資格・担当件数、利用者別月間集計 |
| `/self-check` | 書類・体制の自己点検（虐待防止・BCP・重要事項のウェブ掲載など） |
| `/import` | 取り込み（テンプレート、プレビューと検証、取り込み履歴、事業所情報、バックアップ） |

## 取り込み（`lib/importer.ts`）

- CSV（UTF-8 / Shift_JIS）と Excel（.xlsx）の1枚目のシート
- 見出しの表記ゆれ（例：利用者番号→利用者ID、介護度→要介護度）
- 日付は西暦・和暦（令和8年10月1日、R8.10.1）・Excelの日付、時刻は 9:00 / 9時00分 / Excelの時刻
- 区分は 身体介護2 / 身1生1 / 生活援助3 などを 身体2 / 身体1生活1 / 生活3 にそろえる
- 訪問介護計画は1行＝1サービス枠。2行目以降は計画単位の項目を空欄にできる。曜日は「月・水・金」「月〜金」「毎日」
- 取り込む前にエラー（取り込まない行）と注意を一覧表示

実際の帳票ソフトから出したファイルの列名が違う場合は、`*_FIELDS` の `aliases` に追加する。

## シフト自動作成（`lib/shift.ts`）

- 対象月に有効な訪問介護計画のサービス枠から、日ごとの訪問予定を作る
- 必ず守る条件：資格（身体介護は介護福祉士・実務者研修・初任者研修）、曜日ごとの勤務可能時間、担当しない利用者、訪問の重なり（移動時間を含む）、週の上限時間
- 同じ計画の同じ曜日・時間の枠は、月を通して同じ職員にそろえる。担当希望の利用者・すでに担当している利用者を優先し、残りは負担が少ない職員へ
- 割り当てられない訪問は理由（例：勤務可能時間外（3名））を表示
- 職員の取り込みで、月〜日の勤務可能時間（9:00-17:00 / ○ / ×）、週の上限時間、担当しない・担当希望の利用者を指定できる

## 運営指導チェック（`lib/checks.ts`）

記録：C01 実提供時間と計画区分の乖離 / C02 算定区分・単位数と計画の一致 / C03 計画に基づかない訪問 / C04 2時間ルール /
C05 サービス内容と区分 / C06 特記事項 / C07 利用者確認 / C08 サ責確認 / C09 資格要件 / C10 職員の訪問重複 / C11 訂正履歴 / C12 異変時の報告
計画：C13 同意前のサービス提供 / C14 計画の記載事項 / C15 ケアプランとの前後関係
利用者：C16 要介護認定の有効期間 / C17 契約・重要事項説明
報告：C18 介護報告書の作成・送付

## 定数（`lib/master.ts`）

- 大阪市2級地 訪問介護 11.12円/単位（サービス提供票の別表と同じ。2027年4月の介護報酬改定で見直し）
- 基本単位は2024年度改定値。加算は未計上
